Репозиторий [famelikolbut5/pribor-studio](https://github.com/famelikolbut5/pribor-studio).

Реализовал локальный прототип на Python и FastAPI с веб-формой, JSON-вводом и экспортом карточки в Markdown и JSON. Генерация работает через LLM API, модель по умолчанию GPT-6.1 Sol с запрошенным high.

Основное внимание уделил технической достоверности. Заполненные характеристики переносятся дословно, значения из паспорта проверяются по исходному фрагменту, неизвестные сведения и противоречия вынесены отдельно. Ответ проверяется схемой и кодом, при ошибке содержания допускается одно исправление.

В проект включены два реальных результата, промпт, решения, ограничения и протокол проверки. Прошли 63 Python-теста, 14 тестов ввода JavaScript и проверки интерфейса на трёх размерах экрана. Реальные вызовы модели отделены от мок-тестов. Отдельно сохранён неудачный запрос, который был отклонён проверкой пунктуации.

Основные сложности связаны с различением калибровки и поверки, сохранением поддиапазонов и условий измерения, а также вариативностью и задержкой LLM. Автоматические проверки не заменяют смысловую проверку редактором. Установка, примеры и возможные улучшения описаны в README.
