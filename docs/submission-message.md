Подготовил тестовое задание по генерации товарных описаний.

Репозиторий [famelikolbut5/pribor-studio](https://github.com/famelikolbut5/pribor-studio).

Сделал локальное приложение на Python и FastAPI. Данные можно заполнить через форму или передать в JSON. Сервис обращается к LLM API и формирует карточку с SEO-заголовком, описанием, характеристиками, поисковыми запросами и блоком для менеджера. Результат можно отредактировать и выгрузить в Markdown или JSON.

Основное внимание уделил техническим данным. Добавил проверки исходных значений, обработку неполного ввода и ошибок API. Неизвестные сведения и противоречия выводятся отдельно.

Критичных сложностей не возникло. Отдельно проработал сохранение диапазонов и условий измерения, различие между калибровкой и поверкой, а также между опциями и комплектацией.

В репозитории есть инструкция запуска, два примера, промпт, описание решений и ограничений. Установку и запуск проверил в чистом окружении Windows.
