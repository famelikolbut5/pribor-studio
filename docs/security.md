# Защита локального прототипа

Приложение рассчитано на локальный запуск на `127.0.0.1`. Пользовательская авторизация и публичное размещение в MVP не реализованы.

| Риск | Реализованная мера | Проверка |
|---|---|---|
| Раскрытие ключа | Окружение сервера, исключение `.env`, ключ не включается в ответы | Проверка файлов и тесты API |
| Запрос со стороннего сайта | Разрешённые Host и проверка Origin для POST | Тесты чужого Origin и Host |
| Большое тело без Content-Length | Подсчёт фактических частей до разбора, предел 100 КБ | Тест потока |
| Некорректный Content-Length | Проверка формата и размера без преобразования огромного целого | Тесты заголовков |
| Неоднозначный JSON | Повторяющиеся ключи отклоняются, включая эквивалентные Unicode escape | Python- и JavaScript-тесты |
| HTML и исполняемая ссылка | Текстовые DOM-узлы, CSP, только HTTP/HTTPS для ссылки источника | Код рендера и браузерная проверка |
| Запрос во внутреннюю сеть через source_url | Сервер не скачивает входную ссылку | Тест отсутствия запроса по ссылке |
| Ошибка или обрыв API | Понятные сообщения без сырого тела провайдера и секретов | Мок-тесты, отдельные реальные ответы |
| Неограниченная очередь и ожидание | Три генерации одновременно, максимум одно исправление, 300 секунд на обращение | Тесты лимита и общего таймаута |
| Устаревшая карточка | Сравнение снимка данных, сброс редакторского подтверждения при правке | Браузерные проверки |

Редактор получает CSP, `nosniff`, `SAMEORIGIN` и `no-referrer`. API использует `no-store`. Swagger UI использует CDN FastAPI и является явным исключением из CSP редактора.

Проверяются ошибки авторизации, баланса, модели, лимитов, сети, таймаута, отказа, обрезанного и некорректного ответа. После отказа проверки некорректная карточка не заменяет предыдущую. Результат при этом не считается опубликованным.

Markdown и JSON экспортируются как данные. При дальнейшей публикации внешняя CMS должна применить собственные правила отображения. Товарные данные передаются API-посреднику. Его хранение, подлинность модели, списания и фактическое исполнение параметров не контролируются приложением.

Проверки не являются пентестом или доказательством отсутствия всех уязвимостей. Отмена ожидания в браузере не гарантирует остановку уже начавшейся генерации у провайдера.
