# Интерфейс редактора

Один экран связывает источник, карточку и проверку перед публикацией. Светлая поверхность, спокойный синий акцент, локальный Golos Text. Основной текст 19 px, значения полей 18 px. Ширина описания ограничена для удобного чтения.

На широком экране источник и карточка расположены рядом, редакторская проверка следует отдельным блоком. На узком экране используется одна колонка. Характеристики вводятся многострочными полями с автоматической высотой. Длинные значения не требуют горизонтальной прокрутки.

Вкладки просмотра, Markdown и JSON используют один объект карточки. Сырой экспорт имеет ограниченную высоту и собственную прокрутку. Кнопки копирования и скачивания стоят после него, текст не пересекает панель действий.

Шапка содержит только бренд и навигацию. В карточке нет повторяющихся названий черновика, технических метаданных модели, времени выполнения и подписи сохранённого примера. Статус ожидания виден только во время запроса. Важные ошибки и нехватка данных остаются заметны.

Два примера представлены видимыми переключателями с полными названиями и переносом строк. Выбор применяется кнопкой «Загрузить» и сам по себе не заменяет введённые данные. Всплывающий список и значок обновления не используются.

Заголовок и описание редактируются с мгновенными счётчиками. Изменение текста сбрасывает подтверждение редактора, изменение источника отмечает устаревший результат. Цвет дополняется текстом и символом состояния.

Проверены размеры 1920×1080, 1365×768 и 390×844 CSS px. Фактические измерения и сценарии находятся в [протоколе](docs/verification.md). Скриншоты в [previews](previews) получены из рабочего приложения.
